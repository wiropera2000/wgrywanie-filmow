Privacy Policy

Wgrywanie filmow · Last updated: 21 November 2026

Wgrywanie filmow is a private tool used solely by the owner of the YouTube channels Gdybologia and Illegal There to upload their own videos. It is not available to other users.

YouTube API Services

This tool uses YouTube API Services. By using it, you agree to the YouTube Terms of Service. Google’s handling of data is described in the Google Privacy Policy.

What data the tool accesses

  • Permission to upload videos to the signed-in YouTube channel (scope youtube.upload).
  • Read-only access to the signed-in channel’s basic information, used only to confirm which channel is signed in (scope youtube.readonly).
  • The video files and metadata (title, description, tags, publication time) that the owner chooses to upload.

How data is used and stored

  • Data is used only to upload the owner’s videos and to confirm the signed-in channel.
  • The OAuth access token is stored only on the owner’s own computer, in a file readable only by the owner. No data is stored on any server operated by this tool.
  • A local log on the owner’s computer records each upload (date, channel, video ID, title). It contains no passwords or tokens.

Sharing

No data is sold, shared with third parties or used for advertising. Data is sent only to Google/YouTube through the YouTube API in order to perform the upload. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deleting data

Access can be revoked at any time on the Google security settings page. Revoking access invalidates the stored token; the owner can also delete the local token and log files at any time. Uploaded videos can be managed or deleted in YouTube Studio.

Contact

Questions about this policy can be sent through the contact details on the Gdybologia or Illegal There YouTube channel page.
